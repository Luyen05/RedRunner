## Kiến thức đã học được
1. Hiểu được cấu trúc của một dự án game Unity và cách các thư mục như Assets, Scripts, Prefabs hoạt động.
2. Biết cách làm việc với Scene, GameObject và các Component trong Unity Editor.
3. Thực hành thay đổi các thông số của nhân vật như tốc độ chạy, lực nhảy và trọng lực để quan sát sự thay đổi trong gameplay.
4. Làm quen với việc đọc và phân tích code C# trong Unity, đặc biệt là các script như GameManager và Character.
5. Biết cách sử dụng Git/GitHub để commit và push project lên repository.
